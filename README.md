# Bang & Olufsen Landing Page

A responsive landing page for Bang & Olufsen audio products, built with HTML and SCSS without any frameworks.

## Live Preview

[slysahex.github.io/bang-olufsen-landing](https://slysahex.github.io/bang-olufsen-landing/)

## Design Reference

[Figma design (B&O)](https://www.figma.com/file/DtkQmQ797hk0nI4KfMi2Uq/BOSE-New-Version?type=design&node-id=6817-212&t=ZTV6Gl8NzaWkJ4FK-0)

## Technologies Used

- HTML5 (semantic markup)
- SCSS (variables, partials)
- BEM methodology
- Flexbox and CSS Grid
- Media queries for mobile, tablet and desktop
- Vite (via @mate-academy/scripts) for build and deploy

## Features

- Responsive layout for mobile, tablet and desktop
- Burger menu built with pure CSS (no JavaScript)
- Smooth scrolling to page sections from the menu
- Clickable phone, email and address (opens Google Maps)
- Contact form with required fields that resets after submit
- Optimized WebP images with lazy loading

## Getting Started

1. Clone the repository:

   ```bash
   git clone https://github.com/slysahex/bang-olufsen-landing.git
   cd bang-olufsen-landing
   ```

2. Install dependencies:

   ```bash
   npm install
   ```

3. Start the dev server:

   ```bash
   npm start
   ```

4. Build and deploy to GitHub Pages:

   ```bash
   npm run deploy
   ```
